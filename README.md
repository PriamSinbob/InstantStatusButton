# InstantStatusButton
An mobile widget that instantly shares a short status in social media.

The application allows to install a widget on Android that looks like a button - round, colored with short (up to 10 letters) description what is set.
When clicked, the button instantly sends a preset status to social media: x, facebook, instagram, linkedin.
The widget has settings where the text for the status can be set, it's shortcut to be shown on the button, location to be added (location of device when clicked), which socialmedia to post, login to those and connect.
Example:
Button shows: Yeah!
Clicked: a post on facebook and x appears on personal wall with text: I am feeling great now!
The post includes location.

The purpose is to be able to quickly give short hints of emotions connected to a place, or to easily update ones position without the need to open nor type anything.
